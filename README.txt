GLAMORA JEWELS — DEMO WEBSITE
================================

Files
- index.html: page content
- style.css: responsive design and layout
- script.js: mobile navigation and current year

How to preview
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed for Google Fonts and the example jewellery photos (loaded from Unsplash).

Before publishing for the client
- Confirm product photos, prices, stock, shipping details, return policy and contact preferences with the business.
- Replace the sample/stock jewellery photos with their actual product photos.
- Replace the inspirational quote section with verified customer reviews or remove it.
- Confirm that the Instagram link is correct.
- The page is a visual demo; it does not include checkout, inventory, payment processing or an order-management system.

This is an unsolicited demo concept made to show a possible website direction. It is not an official Glamora Jewels website.
